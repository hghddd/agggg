## Currency Converter App

## Описание
Приложение для конвертации валют с использованием внешнего API. Оно позволяет пользователям выбирать валюты, вводить сумму и получать результат конвертации. Приложение также сохраняет историю конвертаций в файл JSON.

## Установка
1. **Установка зависимостей**:
   ```bash
   pip install requests
   ```

2. **Скопируйте ваш API-ключ** в переменную `API_KEY` в файле `converter.py`. Вы можете получить API-ключ на сайте [exchangerate-api.com](https://www.exchangerate-api.com/).

## Запуск
Запустите приложение командой: bashpython converter.py
## Использование
1. Выберите валюту "From" и "To" из выпадающих меню.
2. Введите сумму в поле ввода.
3. Нажмите кнопку "Convert".
4. Результат конвертации появится в информационном окне.
5. История конвертаций будет автоматически обновляться в таблице внизу окна.

## Функционал
- **Выбор валют**: Возможность выбрать разные валюты для конвертации.
- **Конвертация**: Автоматическое получение текущего курса обмена и расчет результата.
- **История**: Сохранение и отображение истории конвертаций.
- **Валидация**: Проверка правильности введенной суммы (должна быть положительным числом).
